# 第 4 周媒体、文件与权限记录

**关联计划：** `plans/2026-09-10-react-native-native-capabilities-training.md`

## 已实现行为

| 能力     | 当前行为                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------- |
| 头像选择 | 从照片库选择图片；取消时不改变头像。                                                               |
| 拍摄头像 | 请求相机权限后调用系统相机；iOS Simulator 没有相机，必须在真机验证。                               |
| 头像处理 | 用 `expo-image-manipulator` 进行居中正方形裁剪、缩放至 512 × 512、JPEG 0.78 压缩；仅显示本地预览。 |
| 权限拒绝 | 不自动循环请求；不能再次请求时显示“打开系统设置”。                                                 |
| 订单附件 | 用系统文件选择器选择一项附件，复制到缓存目录后只保存名称、MIME 类型、大小与 URI。                  |
| 系统分享 | 仅在 `Sharing.isAvailableAsync()` 为真时打开分享面板；否则显示不可用提示。                         |

## 手工验收清单

- [ ] iOS 真机：首次选择照片并允许权限，确认头像预览更新。
- [ ] iOS 真机：拒绝照片或相机权限，确认页面仍可浏览，且不会重复弹权限框。
- [ ] iOS 真机：在系统设置重新授权后，再次选择或拍摄头像成功。
- [ ] Android 真机：选择 PDF 或图片附件，确认名称、类型和大小显示正确。
- [ ] iOS、Android：分享已选择附件，确认系统分享面板出现。
- [ ] iOS Simulator：点击“拍摄头像”后确认降级提示；不要把它当作相机能力的通过依据。

## 验证范围

- 自动化覆盖头像裁剪尺寸、附件元数据、权限永久拒绝提示、分享不可用提示。
- 物理设备权限状态与系统分享面板无法由当前自动化测试替代。
